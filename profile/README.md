# determlab

**LLM agents improvise. The infrastructure underneath shouldn't.**

We build the deterministic, auditable layer beneath autonomous and AI systems —
every action typed, gated, validated, logged. Same input, same result, every run.

**New here? Start with SHAL** — it gives an AI agent real hardware, gated so it
asks permission before it moves. In a blind test, an agent wrote working,
safety-checked drivers for 4 of 4 devices (a sensor, a power supply, a web API,
a robot vacuum) from documentation alone.

| Project | What it does |
|---|---|
| **[SHAL](https://github.com/determlab/shal)** · start here | Turn a whole lab — hardware *and* software — into safe, typed, permission-gated tools for an AI agent. Writes are gated; reads aren't. |
| **[Bricks](https://github.com/determlab/bricks)** | Deterministic execution — compose a pipeline once, run it forever. No LLM in the loop, zero tokens per run. |
| **[Predictor](https://github.com/determlab/predictor)** | ML-driven fail-fast for hardware test — abort a suite early when failure is predicted, safety rules before any model. |
